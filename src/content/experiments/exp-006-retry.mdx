## Abstract

Retry is meant to be the place where a college's project work stops disappearing.
Projects are archived, they form a fork lineage so a later team can build on an
earlier one, and faculty grade them with AI assistance but a human approves every
grade. An idea hub collects ideas nobody has built yet.

## What exists

- A full requirements document, architecture, database design, API and WebSocket
  event specifications, a security document and a decision log.
- A monorepo scaffold with Docker Compose, migrations and a seed step.
- Around 65 commits so far.

## Honest status

The planning is thorough and the product is not. The repository says Phase 0:
documentation complete, code scaffold in progress. The team plan assumes twelve
months, and the build has not got far into it yet.
