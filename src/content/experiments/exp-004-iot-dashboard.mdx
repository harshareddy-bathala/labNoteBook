## Abstract

This project explored real-time data visualization patterns for IoT sensor networks, with a focus on threshold-based alerting and trend summarization.

## Technical Approach

- MQTT broker for sensor data ingestion
- React-based dashboard with real-time updates
- Configurable alert thresholds per sensor type
- Historical trend analysis with charting library

## Outcome

The dashboard successfully demonstrated real-time sensor monitoring capabilities with sub-second latency updates.
