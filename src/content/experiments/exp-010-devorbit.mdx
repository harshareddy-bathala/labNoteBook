## Abstract

DevOrbit started as a way to track what I was learning and ended up as a
full application. It has a stack tracker where technologies move through learning
stages, a project manager that connects to GitHub, and a resource library with tags.
Data lives in Firestore and the front end is React with Tailwind.

## What it is good for

It has a CI/CD workflow and a written design system, which is more process than most
of my earlier projects had. About 39 commits over three months.
