## Abstract

This is three repositories treated as one experiment. The first, QuantumFacts, is a
fully automated Shorts generator built on free tiers: it writes a script, narrates it
with text-to-speech, adds word-by-word captions, picks background footage and
uploads. Shortsmith is a later Python pipeline for the same job. The third is a
link-in-bio site with guides and media for Instagram publishing.

## What it taught me

Pipelines like this live or die on asset management and failure handling, not on the
model call.
