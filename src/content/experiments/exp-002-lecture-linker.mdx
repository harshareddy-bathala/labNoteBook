## Abstract

Lecture Linker explored automatic note generation from audio recordings, combining speech-to-text transcription with concept extraction and linking.

## Technical Approach

- OpenAI Whisper for accurate lecture transcription
- NLP pipeline for concept extraction
- Graph-based concept linking
- Markdown output for note portability

## Outcome

Demonstrated viable automatic note generation, though concept linking accuracy varied by lecture subject density.
