## Abstract

Budget Buddy was my first exploration into mobile development with React Native, building a personal finance tracking app with Firebase backend.

## Technical Approach

- React Native for cross-platform mobile development
- Firebase for authentication and real-time database
- Category-based expense tracking
- Weekly and monthly spending visualizations

## Outcome

Successfully built a functional finance tracker that I used personally for several months. Archived after switching to a more mature solution.
