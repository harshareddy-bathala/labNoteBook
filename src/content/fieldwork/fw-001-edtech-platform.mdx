## Project Summary

Built an enterprise-grade real estate platform for Bangalore-based Bathala
Enterprises with a CMS-style admin experience for managing properties and
services.

## What I Built

- Public site for property listings, services, and SEO landing pages
- Secure admin dashboard with full CRUD workflows
- Supabase-backed contact management with optional email notifications
- Authentication and authorization for admin-only operations
- Responsive UI with performance and security hardening

## Tech Stack

Next.js (App Router), TypeScript, Tailwind CSS, Supabase (Auth + PostgreSQL),
React Hook Form + Zod, and Framer Motion.

## Live

- https://bathala-enterprises.vercel.app/

## Outcome

Delivered a production-ready web platform with content management capabilities
that supports ongoing updates without code changes for day-to-day property and
service operations.
